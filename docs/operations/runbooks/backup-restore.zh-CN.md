# 备份和恢复操作手册

[English](backup-restore.md) | 简体中文

使用 [PostgreSQL 和密钥备份/恢复](../backup-and-restore.zh-CN.md)中的命令和保留策略。

1. 从脱离主机存储中选择加密的 `.dump.age` 和匹配的 SHA-256。在接触目标之前验证校验和、年龄解密和 `pg_restore --list`。
2. 仅恢复到新的隔离 PostgreSQL 实例。从单独的加密恢复包中恢复签名/CA 材料。
3. 启动匹配的控制平面映像，应用前向迁移，并验证表计数、已知玩家/管理员访问权限、旧签名清单以及中继重新注册/重新连接。
4. 确认旧的内存连接/分配预计不会恢复。在验证结束之前保持环境隔离。
5. 在 `docs/testing/v1.1/restore-test-report.md` 中记录备份 ID/哈希、RPO、开始/结束/RTO、模式/映像版本、行计数、失败和运算符。仅在每个必需的检查通过后才发布文本文件成功时间戳。
