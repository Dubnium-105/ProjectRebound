# V1.1 发布清单

[English](release-checklist.md) | 简体中文

记录每个检查项目的 UTC 时间戳和证据链接。

- [ ] 候选者是 `main` 上经过审核的提交； CI 和图像来源成功了。
- [ ] 控制平面和边缘中继图像引用是不可变的，并且记录摘要。
- [ ] 发布记录包括提交、构建时间、Go 版本、协议 2 和架构 16。
- [ ] 在不打印机密的情况下检查了生产配置、签名密钥、中继 CA 和管理员恢复访问权限。
- [ ] 加密 PostgreSQL 备份、校验和、脱离主机复制，验证成功。
- [ ] `scripts/release/preflight.sh` 已完成，未跳过关键检查。
- [ ] V1.1 迁移已确认仅扩展/迁移；不存在合同操作。
- [ ] 控制平面运行状况、客户端配置、内部指标、身份验证、房间、WebSocket 和中继分配烟雾测试已通过。
- [ ] Canary 流量在完全流量切换之前达到错误率和延迟阈值。
- [ ] 中继节点通过 DRAINING → 零分配 → 部署 → READY 一次升级一个。
- [ ] 每个中继都会报告一个新的心跳、`control_connected=1`、足够的证书过期余量以及支持运行时更新的映像。
- [ ] 没有 cron、systemd 计时器、监视器或 soak runner 重新启动健康的中继；仅在确认进程/容器故障后才运行恢复。
- [ ] 控制平面重新连接检查确认所有中继节点都可以使用其当前证书建立 mTLS。
- [ ] Prometheus 目标/规则和所有 V1.1 Grafana 仪表板均正常。
- [ ] 动态 Grafana 服务目标包括清单中的每个在线中继，而不是固定节点列表。
- [ ] 观察窗口在没有 API、数据库、Redis、Relay BIND/迁移、证书更新、内存或 goroutine 警报的情况下完成。
- [ ] 24小时中继浸泡，保持健康节点持续在线；故障注入结果单独记录。
- [ ] 以前的不可变映像和经过测试的回滚命令仍然可用。
- [ ] 发布记录和操作员签核已存档。
